CHEMLAB-3D — басқа сайтта жариялау нұсқаулығы
================================================

Бұл папкада CHEMLAB-3D толық сайты бар:
  index.html  — басты бет
  app.js      — қосымша коды
  config.js   — БАПТАУЛАР (AI кілті осында)
  data/       — 15 тақырыптың мазмұны (t01.js … t15.js)

Кіру құпия сөзі: chem2026

------------------------------------------------
1-ҚАДАМ. AI көмекшіні қосу (Google Gemini, тегін)
------------------------------------------------
claude.ai-дан тыс жерде AI көмекші Gemini арқылы жұмыс істейді.

1) https://aistudio.google.com/apikey бетіне Google аккаунтыңызбен кіріп,
   «Create API key» батырмасын басыңыз. Кілт «AIza…» деп басталады.
2) config.js файлын Блокнотпен ашып, кілтті тырнақшаның ішіне қойыңыз:
     geminiKey: "AIzaSy....",
3) Файлды сақтаңыз.

МАҢЫЗДЫ: config.js ішіндегі кілтті сайтқа кірген кез келген адам көре алады.
Бөтен адам пайдаланбауы үшін кілтке шектеу қойыңыз:
  Google Cloud Console → APIs & Services → Credentials → кілтіңізді ашыңыз →
  Application restrictions → «Websites» → өз сайтыңыздың мекенжайын жазыңыз
  (мысалы: https://chemlab3d.netlify.app/*) → Save.

Кілт қойылмаса да көмекші жұмыс істейді — офлайн режимде платформадағы
лекция, практика және зертхана материалынан ең жақын бөлімді тауып береді.

Мұғалім өз құрылғысында кілтті сайттың ішінен де енгізе алады:
🤖 → ⚙ → кілтті қойып «Сақтау» (тек сол браузерде сақталады).

------------------------------------------------
2-ҚАДАМ. Сайтты жариялау
------------------------------------------------
А) Netlify (ең оңай, тегін):
   1) https://app.netlify.com/drop бетін ашыңыз.
   2) Осы папканы (zip емес, ашылған папканы) бетке сүйреп тастаңыз.
   3) Бірнеше секундтан кейін сілтеме шығады (…netlify.app). Дайын!

Ә) GitHub Pages:
   1) GitHub-та жаңа репозиторий ашып, барлық файлдарды жүктеңіз.
   2) Settings → Pages → Branch: main → Save.

МАҢЫЗДЫ: index.html-ді компьютерде екі рет басып ашсаңыз (file://),
кейбір браузерлерде жұмыс істемеуі мүмкін — сайтты міндетті түрде
хостингке (Netlify т.б.) жариялаңыз.
